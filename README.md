# Dog Breed Detection Web App

## Overview
This project is a **web-based Dog Breed Detection application** that identifies the breed of a dog from an uploaded image. It uses a **pre-trained MobileNet model** for image classification and is deployed via **Streamlit**, providing an interactive and user-friendly interface.

Users can upload an image of a dog, and the system predicts the breed with high accuracy. The model leverages transfer learning from **MobileNet**, allowing efficient feature extraction and classification without training from scratch. The Streamlit interface ensures real-time predictions with minimal latency, making it accessible even for non-technical users.

---

## Features
- Upload an image of a dog and predict its breed in real-time
- Built with **MobileNet** (pre-trained on ImageNet)
- Streamlit-based interactive web interface
- Handles multiple dog breeds with high accuracy
- Lightweight and fast, suitable for real-time usage
- Supports images in common formats (JPEG, PNG)

---

## Technology Stack
